# muriburs — پروژه اندروید (نسخه توسعه)

این بسته یک پروژه قابل ساخت برای Android Studio/GitHub Actions است و رابط کاربری ماژولار تمام بخش‌های توافق‌شده را دارد.

## وضعیت مهم
این نسخه **نسخه عملیاتیِ تأییدشده بازار نیست**. رابط و چارچوب ماژول‌ها آماده شده، اما اتصال زنده به منابع بازار، اعتبارسنجی پاسخ APIها، تحلیل واقعی کدال/اختیار معامله و آزمون تاریخی هنوز باید تکمیل و آزمایش شوند. در جاهایی که داده معتبر در دسترس نیست، برنامه به‌جای ساختن عدد، «داده موجود نیست» نمایش می‌دهد.

## امکانات موجود در رابط
- داشبورد و فهرست حداکثر ۳ فرصت
- قیمت و تاریخچه
- تکنیکال
- جریان پول حقیقی/حقوقی
- حجم غیرعادی و نشانه‌های تجمیع
- بنیادی و کدال
- اختیار معامله Call/Put
- امتیاز غربالگری (نه احتمال رشد)
- محدوده ورود، حد ضرر و اهداف (فقط پس از دریافت داده معتبر)
- گزارش عملکرد و ثبت نتیجه بررسی‌ها
- وضعیت منبع داده و تازگی داده

## ساخت APK با GitHub Actions
1. فایل ZIP را روی کامپیوتر Windows استخراج کن.
2. در GitHub یک مخزن جدید بساز.
3. محتویات پوشه پروژه را در مخزن بارگذاری کن (همه فایل‌ها، از جمله `.github`).
4. وارد زبانه **Actions** شو و workflow با نام **Build muriburs APK** را اجرا کن.
5. پس از پایان موفق، از بخش Artifacts فایل `muriburs-debug-apk` را دریافت کن.
6. APK را به گوشی Xiaomi 12T Pro منتقل و نصب کن.

## ساخت محلی
پروژه را با Android Studio باز کن و اجازه بده Gradle Sync انجام شود؛ سپس از منوی Build گزینه Build APK(s) را بزن.

## محدودیت‌های داده و تحلیل
- اطلاعات عمومی حقیقی/حقوقی، هویت مشتریان هر کارگزاری را نشان نمی‌دهد؛ خرید مشتریان مفید/فارابی قابل انتساب نیست مگر منبع معتبر جداگانه وجود داشته باشد.
- درصد احتمال رشد تا زمان بک‌تست و کالیبراسیون خارج از نمونه نمایش داده نمی‌شود.
- اختیار معامله بدون زنجیره قرارداد به‌روز و معتبر تحلیل/پیشنهاد نمی‌شود.
- اجرای سفارش، اتصال حساب کارگزاری و معامله خودکار عمداً وجود ندارد.
- برنامه از اینترنت گوشی استفاده می‌کند؛ اجرای دائمی در پس‌زمینه تضمین نمی‌شود و تابع محدودیت باتری و اندروید است.

## گام توسعه بعدی
برای عملیاتی‌شدن باید برای هر منبع داده قرارداد API پایدار، نمونه پاسخ واقعی، تست parser و پایش تازگی داده اضافه شود. تا آن زمان هیچ سیگنال خرید زنده‌ای تولید نمی‌شود.
